| 구성 | 원안(유료) | **무료 전용안** | 비고 |

| 웹사이트 | Vercel Pro $20 | **Cloudflare Pages 무료** (정적 웹앱) | Vercel 무료(Hobby)는 약관상 회사 업무 사용 금지라 제외. Cloudflare 무료는 상업 이용 금지 조항을 찾지 못했으나 "중요하지 않은 개인·취미 프로젝트용"으로 안내됨 → 원문 약관 재확인 필요 |
| 웹 구조 | Next.js 서버 | **React 정적 앱 + Supabase 직접 연결** | 서버가 없어 무료 호스팅 어디든 가능. 권한은 Supabase RLS가 지킴 |

| 알림 | 알림톡 (건당 6.5~13원) | **이메일(Gmail) + 무료 메신저 봇** | 카카오 알림톡은 무료가 없음 |
| **월 합계** | 약 4.8~16만 원 | **0원** (사무실 PC 전기료 제외) | |

### AI 초안 — 무료 3안

| 안 | 방식 | 장점 | 단점 |
|---|---|---|---|
| **A. 지식DB 템플릿 (AI 없음)** | 문의 키워드·규칙으로 유형을 고르고, 지식 DB의 표준 답변을 그대로 넣어 초안 생성 | 완전 무료, 고객 정보가 외부로 안 나감, 지어내는 답변 없음 | 문장이 정형적, 리뷰마다 다른 답글 쓰기는 약함, 분류 정확도 낮음 → 자동 등록 범위 좁게 |
| **B. 사무실 PC에서 로컬 AI (Ollama + 공개 모델)** | 사무실 PC에 무료 AI 모델을 설치해 직접 실행 | 무료, 고객 정보가 외부로 안 나감 | PC 사양 필요(메모리 16GB 이상, 그래픽카드 있으면 좋음). 한국어 품질은 Claude보다 낮음. 상업 이용 가능한 모델만 사용(Gemma·Qwen 등) |
| C. Gemini API 무료 구간 | 구글 AI 무료 호출 | 품질 좋음, 설정 쉬움 | **무료 구간은 입력·출력을 구글이 제품 개선에 쓰고 사람이 검토할 수 있음** (2026-03 약관). 요실금·건강 관련 고객 문의가 외부에 넘어가는 문제 → **비추천** |

**추천: A로 시작 → 사무실 PC 사양이 되면 B를 추가.** 규칙 안전장치(③ 사람 전용 차단, 금지 표현 검사, DRY_RUN)는 어느 안이든 똑같이 적용합니다. A안일 때 ① 자동 처리는 "키워드가 지식 DB 항목과 정확히 맞는 배송·사이즈·세탁 문의"로만 한정합니다.

### 알림 — 무료 안

| 안 | 장점 | 단점 |
|---|---|---|
| **이메일 (Gmail SMTP)** — 기본·대체 채널 | 무료(하루 500통), 확실, 발송 기록 남음 | 휴대폰 메일 앱 알림을 켜야 함 |
| 카카오워크 무료 플랜 봇 | 카카오 계열, 그룹방 형태 | 무료 플랜에서 봇 사용 가능 여부 **미확인**, 별도 앱 설치, 2026-11 보안 사고 보도 |
| 텔레그램 봇 | 무료, 그룹방 지원, API 안정적, 발송 성공 응답 확인 가능 | 카카오 아님, 별도 앱 설치 |

**추천: 이메일을 기본으로 개발 → 담당자님이 메신저(카카오워크 또는 텔레그램)를 고르면 추가.** 카카오톡 일반 단톡방 자동 전송은 공식 방법이 없고 비공식 앱은 계정 정지 위험이 있어 계속 제외합니다.

### 무료안에서 달라지는 점 (감수해야 할 것)
- 사무실 PC가 꺼지면 수집·등록·알림이 전부 멈춥니다. (작업기 멈춤 감시는 Supabase 무료 기능으로 이메일 경고)
- 사무실 인터넷이 **고정 IP가 아니면** 마켓 API를 안정적으로 쓸 수 없습니다(쿠팡은 IP 변경 10회 제한). 이 경우 문의 API 수집은 보류하고 파일 업로드 방식만 가능 → 확인 필요.
- AI 품질은 Claude보다 낮으므로 사람 승인 비중이 커집니다.

### 2차 결정 (2026-11-23)

| 항목 | 결정 | 메모 |
|---|---|---|
| 작업기 | **사무실 PC** | 고정 IP 여부 확인 필요 |
| AI | **지식 DB 표준 답변 방식 (AI 없음)** | |
| 알림 | **텔레그램 봇(그룹방) + 이메일 대체** | 무료 중 푸시 확실·그룹방·발송 성공 응답 확인 가능. 카카오워크는 무료 봇 가능 여부 미확인 |
| 웹사이트 | 담당자 요청: **Claude 사이트(Artifact)** → 검토 결과 아래 이유로 **Cloudflare Pages 무료 유지 제안** | |

**Claude Artifact를 대시보드로 쓰기 어려운 이유**
- Artifact 페이지의 공유 DB는 페이지 화면과 Claude 대화 세션에서만 읽고 쓸 수 있습니다. **사무실 PC 작업기가 수집한 문의를 넣을 공식 통로가 없습니다** → 문의가 자동으로 쌓이지 않음.
- 담당자 전원이 같은 조직의 claude.ai 계정이 있어야 합니다.
- 결론: 화면은 Cloudflare Pages(무료) + Supabase(무료). 작업기는 Supabase에 쓰고 웹은 Supabase를 읽음.

**지식 DB 데이터 수집 원칙**
- 1순위: **우리 회사 데이터** — 스마트스토어·쿠팡 API로 과거 문의·답변 이력 자동 수집(Phase 1), 판매자센터 리뷰 엑셀, 우리 상세페이지·사이즈표·사용설명서
- 2순위: 경쟁사 공개 페이지는 **질문 유형 파악용 참고**만. 본문·리뷰·답변 대량 복제(크롤링)는 하지 않음
  - 이유: 데이터베이스 제작자 권리(저작권법), 부정경쟁방지법상 데이터 부정사용, 사이트 약관, 리뷰 작성자 개인정보 문제 → 법적 위험
  - 실무 이유: 경쟁사 제품의 사이즈·흡수량·소재는 우리 제품과 다름 → 그대로 넣으면 **우리 고객에게 틀린 정보**가 나감 (의료기기 표현 규정 위반 위험까지)
- 제공 예정: 요실금팬티·고관절 보호대 등 카테고리별 **예상 질문 유형 목록**(직접 작성) → 담당자님이 표준 답변만 채우면 되는 엑셀 템플릿

## 2. 전체 구조

```
 담당자 PC·휴대폰 ──▶ Vercel (Next.js 웹) ──▶ Supabase (DB·로그인·파일)
                                                   ▲      │
                              수집 결과·하트비트 기록 │      │ 등록 대기·설정 읽기
                                                   │      ▼
                         작업기 (고정 IP, 평일 업무시간만 동작)
                         ├─ 문의 수집  ── 네이버/쿠팡 API (키는 작업기 .env에만)
                         ├─ AI 분류·초안 ── Claude API
                         ├─ 승인된 답변 등록 (DRY_RUN=true 기본)
                         ├─ 리뷰 파일 처리 (업로드 파일 / 선택: 자동 다운로드)
                         └─ 알림 발송 ── 솔라피(알림톡→문자) / 이메일
```

- 웹은 마켓 API를 부르지 않습니다. "승인" = DB의 `post_jobs`에 등록 대기 행 추가 → 작업기가 1분마다 가져가 등록.
- 작업기는 1분마다 `worker_heartbeat` 기록. 웹 상단에 **작업기 상태(정상/멈춤)** 크게 표시. 10분 이상 멈추면 → 웹 경고 + (Supabase 쪽 예약 함수 `pg_cron`이 감지해) 이메일 알림. 작업기가 죽으면 작업기가 알림을 못 보내므로, 감시는 작업기 밖(Supabase)에서 합니다.

### 작업기 위치 비교

| | 사무실 PC | Lightsail 서울 2GB |
|---|---|---|
| 월 비용 | 0원 | 약 17,000원 ($12) |
| 고정 IP | 회사 인터넷 계약에 따라 다름 (확인 필요) | 기본 제공 |

## 3. 기술 스택 (원안 유지, 세부 확정)

- pnpm 모노레포, TypeScript 전 구간
  - `apps/web` Next.js(App Router) + Tailwind → Vercel
  - `apps/worker` Node.js 22 LTS, `node-cron`(시간대 Asia/Seoul), NSSM 서비스
  - `packages/shared` **Drizzle ORM**(SQL에 가깝고 Supabase와 궁합이 좋아 Prisma 대신 채택), `rules.yaml`, `forbidden_phrases.yaml`, 프롬프트, 타입
- Supabase: Postgres + Auth(이메일/비밀번호) + Storage(리뷰 원본 파일) + RLS
- 알림: `solapi` 공식 SDK, 이메일은 `nodemailer`(Gmail SMTP 앱 비밀번호)
- 브라우저 자동화(선택 기능): Playwright, 작업기에서만
- 테스트: Vitest, 마켓·알림은 목(mock)

## 4. 운영 시간 엔진

- 설정: `OPERATING_START=09:00`, `OPERATING_END=18:00`, `TZ=Asia/Seoul`, 요일 월~금
- 휴일: 공공데이터 특일 API로 자동 갱신 + 2026·2027년 목록 내장 + 웹에서 회사 휴무일 추가
- 모든 스케줄 작업은 실행 직전 `isOperatingNow()` 검사 → 밖이면 아무것도 안 함
- 운영 시작 첫 실행: 밀린 기간 전체 수집(쿠팡 7일 창 겹쳐 조회) → 분류 → "휴일 동안 n건" 요약 알림 1건
- 마감 알림: 다음 날이 비운영일인 운영일 17:30
- `OFFHOURS_SAFE_AUTO=false` 기본. **참고:** 쿠팡은 처음엔 전부 ②승인 경로라, 이 설정을 켜도 쿠팡 고객센터 24시간 종료 문제는 해결되지 않습니다. 금요일 오후 쿠팡 고객센터 문의는 17:00·17:30에 별도 기한 경고를 보내는 것으로 보완합니다.

## 15. 월 비용표 (VAT 별도, 1$=1,400원, 월 21 운영일)

### AI 비용 계산 근거
- 분류(Haiku 5.5): 입력 약 2,000토큰 + 출력 200 → **건당 약 $0.0003**
- 초안(Sonnet 5.5): 입력 약 5,000토큰(규칙·지식·상품정보) + 출력 약 1,500(사고 포함) → **건당 약 $0.025**
- 합계 **건당 약 $0.025 (약 36원)**. 프롬프트 캐싱을 쓰면 입력 비용이 더 줄어듭니다(보수적으로 미반영).
