# DRC CS 허브 설치 가이드

> **메인 PC 한 대에만 설치**합니다. 같은 사무실의 다른 PC는 크롬으로 접속만 하면 됩니다. 모두 **무료**입니다.
> 키·비밀번호는 채팅에 붙여넣지 마세요. 막히면 화면을 캡처해서 보내주세요.

```
 [메인 PC]  허브 프로그램 ─ 문의 수집 + 데이터 보관 + 화면 제공
     ▲
     │ 크롬으로 http://메인PC주소:3000
 [다른 PC]  설치 없음
```

---

## 1. 메인 PC에 설치 (처음 한 번, 약 15분)

1. **Node.js 설치** — https://nodejs.org → 왼쪽 **LTS** 버튼 → 받은 파일 실행 → 계속 [다음]
2. **프로그램 받기** — https://github.com/wonyul01-collab/drc-cs-hub → 초록색 **Code** 버튼 → **Download ZIP**
3. 받은 ZIP을 **오른쪽 클릭 → 압축 풀기** → 풀린 폴더를 `C:\drc-cs-hub` 로 옮기기
   (폴더 안에 `1-install.bat` 이 보이면 맞습니다)
4. **`1-install.bat` 더블클릭** → "설치 완료!"가 나오면 창 닫기
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**

## 2. 마켓 키 넣기 (약 5분)

1. **`3-settings.bat` 더블클릭** → 메모장이 열립니다
2. `=` 뒤에 값을 채우고 **저장**(Ctrl+S)
   | 항목 | 어디서 |
   |---|---|
   | `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | 네이버 커머스API센터 → 애플리케이션 ID / 시크릿 |
   | `COUPANG_VENDOR_ID`, `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY` | 쿠팡 Wing → 판매자정보 → 추가판매정보 → OPEN API 키 |
   | `COUPANG_KEY_ISSUED_AT` | 쿠팡 키 발급일 (예: `2026-11-20`) — 만료 경고용 |
   | `BACKUP_DIR` (선택) | 백업 받을 폴더. 예: 구글 드라이브 폴더 |
   - `DRY_RUN=true` 는 **그대로 두세요** (마켓에 실제 답변 등록 안 함)
   - 이 파일은 `C:\Users\(사용자)\DRC-CS-Hub-Data\settings.env` 에 저장됩니다

3. **이 PC의 IP가 마켓에 등록돼 있는지 확인** — 크롬에서 "내 IP 확인" 검색 → 나온 숫자가
   - 네이버 **커머스API센터 → 애플리케이션 → API 호출 IP**
   - 쿠팡 **Wing → OPEN API 키 → 연동 IP**
   에 들어 있어야 합니다. (쿠팡은 IP 수정 횟수 제한이 있으니 정확히 한 번에)

4. **`4-check.bat` 더블클릭** → 채널마다 ✅/❌ 표시
   - 결과 파일 `C:\Users\(사용자)\DRC-CS-Hub-Data\probe-결과.txt` 를 **개발자(Claude)에게 보내주세요**
     (키·고객 내용은 없고 건수와 항목 이름만 들어 있습니다)

## 3. 허브 켜기

1. **`2-start.bat` 더블클릭** → 검은 창에 아래처럼 나오면 성공
   ```
   DRC CS 허브가 켜졌습니다.
     이 PC에서:      http://localhost:3000
     다른 PC에서:    http://192.168.0.15:3000   ← 이 주소를 메모
   ```
   - **이 검은 창은 닫지 말고 최소화**해 두세요 (닫으면 허브가 꺼집니다)
   - "Windows 보안 경고 — 방화벽" 창이 뜨면 **개인 네트워크** 체크 → **액세스 허용**
2. 메인 PC 크롬에서 **http://localhost:3000** → **관리자 계정 만들기** (처음 한 번)
3. 로그인 → 상단 **담당자** 메뉴 → 다른 PC 담당자 계정 만들기 (이름·아이디·비밀번호)

## 4. 다른 PC에서 접속

- 크롬 주소창에 3-1에서 메모한 주소 입력 (예: `http://192.168.0.15:3000`) → 로그인
- **즐겨찾기(★)** 해두면 편합니다
- 접속이 안 되면: 메인 PC의 검은 창이 켜져 있는지, 방화벽 "액세스 허용"을 눌렀는지 확인

### 다른 PC 접속이 안 될 때 ("사이트에 연결할 수 없음")

1. **주소 확인** — 다른 PC에서는 `localhost`가 아니라 메인 PC 검은 창의 **"다른 PC에서: http://192.168.…:3000"** 주소를 입력해야 합니다.
2. **방화벽 열기 (메인 PC에서 한 번)** — `C:\drc-cs-hub\5-allow-other-pc.bat` **오른쪽 클릭 → 관리자 권한으로 실행**.
   같은 사무실 네트워크에서만 접속을 허용합니다 (밖에서는 여전히 접속 불가).
3. **같은 공유기인지 확인** — 두 PC 모두 시작 → `cmd` → `ipconfig` 입력 → **IPv4 주소**의 앞 세 자리 비교
   - 예: 메인 `192.168.0.15`, 다른 PC `192.168.0.23` → 같은 망 ✅
   - 예: 메인 `192.168.0.15`, 다른 PC `192.168.1.40` → **다른 공유기** ❌ — 화면을 캡처해서 보내주세요

## 4-2. 알림 메일 켜기 — 관리자 (한 번만)

**① 보내는 메일 계정 준비** (회사 메일 계정 하나)
- **네이버 메일**: 네이버 메일 → 왼쪽 아래 **환경설정** → **POP3/IMAP 설정** → **IMAP/SMTP 사용: 사용함** → 저장
  - 네이버 2단계 인증을 쓰는 계정이면: 네이버 **내정보 → 보안설정 → 2단계 인증 → 애플리케이션 비밀번호 관리**에서 비밀번호를 하나 만들어 그걸 사용
- **Gmail**: Google 계정 → **보안** → 2단계 인증 켜기 → **앱 비밀번호** 만들기 (16자리)

**② 메인 PC에 넣기**
- `3-settings.bat` 더블클릭 → 맨 아래 **MAIL_USER=** 에 메일 주소, **MAIL_PASSWORD=** 에 비밀번호(또는 앱 비밀번호) → 저장
- 허브 검은 창 닫고 `2-start.bat` 다시 실행

**③ 받는 사람 정하기**
- 허브 화면 **담당자** 메뉴 → 각 사람 **이메일 설정** → 알림 받을 주소 입력
- **홈 → 관리 → ✉ 테스트 메일 보내기** → 메일이 오면 완료 (안 보이면 스팸함 확인)

**언제 메일이 오나요?** (평일 업무시간에만, 고객 개인정보는 넣지 않음)
| 알림 | 때 |
|---|---|
| 신규 문의 요약 (③·②·① 건수 + 바로가기) | 새 문의가 있으면 15분 단위로 묶어서 |
| 쿠팡 고객센터 문의 기한 임박 | 답변 기한 4시간 전 |
| 휴일 다음 날 아침 요약 | 월요일·연휴 다음 날 09:00 |
| 휴일 전 마감 (미처리 건수) | 금요일·휴일 전날 17:30 |
| 오늘 처리 현황 | 매일 17:50 |
| 수집 실패 / 쿠팡 키 만료 임박 | 관리자에게만 |

## 4-3. 문의 처리하는 법 (모든 담당자)

1. **통합 창구**에서 문의 클릭 → 다른 사람이 이미 보고 있으면 **"○○님 처리 중"** 표시 (같이 고치는 사고 방지)
2. 초안을 읽고 필요하면 고친 뒤 **✅ 승인** (고쳤으면 "수정한 내용으로 승인")
   - 쓰면 안 되는 표현·고정 문구 누락이 있으면 승인이 막히고 이유가 나옵니다
   - **③ 사람 전용**은 승인 버튼이 없습니다 → 판매자센터에서 직접 답변
3. **📋 복사하기** → **판매자센터 열기** → 답변 칸에 붙여넣기 → 등록
4. 허브로 돌아와 **✔ 직접 처리 완료** (안 눌러도 다음 수집 때 판매자센터 답변이 확인되면 자동으로 정리됩니다)
- 초안이 엉뚱하면 **↩ 반려**(사유 기록) → 고치거나 **지식 DB로 다시 만들기**

## 4-1. 지식 DB(표준 답변) 넣기 — 관리자

1. 허브 화면 상단 **지식 DB** → **⬆ 엑셀 올리기** → 개발자가 보낸 `지식DB_샐리브_초안.xlsx` 선택 → 확인
2. "올리기 완료"가 나오면 끝. 이미 들어와 있던 문의의 초안도 새로 만들어집니다
3. 답변을 더 채우거나 고칠 때: **⬇ 엑셀로 내려받기** → 엑셀에서 고치고 저장 → **⬆ 엑셀 올리기**
   - 엑셀 안 「사용법」 시트에 규칙이 적혀 있습니다
   - 답변이 비어 있는 '예상 질문' 줄은 답변을 채우고 **사용(Y/N)** 을 **Y** 로 바꾸세요

## 5. 메인 PC를 켤 때 자동으로 허브 켜기 (권장)

1. 키보드 **윈도우키 + R** → `shell:startup` 입력 → 확인 → 폴더가 열림
2. `C:\drc-cs-hub\2-start.bat` 을 **오른쪽 클릭 → 바로 가기 만들기** → 만들어진 바로 가기를 방금 열린 폴더로 옮기기
3. **절전 끄기**: 설정 → 시스템 → 전원 → 화면 및 절전 → 절전 모드 **안 함**

> 메인 PC의 IP 주소는 공유기가 바꿀 수 있습니다. 다른 PC에서 갑자기 접속이 안 되면 메인 PC 검은 창의 "다른 PC에서" 주소를 다시 확인하세요.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 상단 빨간색 "메인 PC에 연결할 수 없습니다" | 메인 PC 켜짐? 검은 창 켜짐? |
| 판매자센터엔 있는데 허브에 예전 문의가 없음 | 홈 → **관리 → 최근 30일 문의 다시 가져오기** (업무시간에 1분 안에 시작). 판매자센터에서 이미 답변한 문의는 통합 창구 '전체 상태'에서 보임 |
| 상단 노란색 "마켓 키가 설정되지 않아…" | `3-settings.bat` 으로 키 입력 → 검은 창 닫고 `2-start.bat` 다시 |
| 점검 결과 쿠팡 ❌ 403 | 메인 PC IP가 Wing 연동 IP에 등록됐는지 (등록 후 최대 30분) |
| 점검 결과 네이버 ❌ 401/403 | 애플리케이션 ID/시크릿 오타, API 호출 IP 등록 |
| 점검 결과 네이버 ❌ 400 | 정상일 수 있음 — 결과 파일을 개발자에게 보내주세요 |
| "3000번 포트를 이미…" | 허브가 이미 켜져 있음 (작업 표시줄의 다른 검은 창 확인) |
| 비밀번호를 잊음 | 관리자가 **담당자** 메뉴 → 비밀번호 변경 |
| 쿠팡 키 만료 경고 | Wing에서 재발급 → `3-settings.bat` 에서 값·발급일 수정 → 허브 다시 켜기 |
