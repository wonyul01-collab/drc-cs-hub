> 처음 한 번만 하면 됩니다. 모두 **무료**입니다. 순서대로 따라 하세요. 막히면 화면을 캡처해서 보내주세요.
> **비밀값(키·비밀번호)은 채팅에 붙여넣지 마세요.**

| 단계 | 할 일 | 걸리는 시간 |
|---|---|---|
| 1 | Supabase(DB) 만들기 | 10분 |
| 2 | 관리자 계정 만들기 | 5분 |

## 1. Supabase(DB) 만들기

1. https://supabase.com 접속 → **Start your project** → GitHub 또는 이메일로 가입 (무료 플랜)
2. **New project**
   - Name: `drc-cs-hub`
   - Database Password: 아무거나 길게 (메모해 두기)
   - Region: **Northeast Asia (Seoul)**
3. 프로젝트가 만들어지면(1~2분) 왼쪽 메뉴 **SQL Editor** → **New query**
4. 이 저장소의 `supabase/migrations/0001_init.sql` 파일 내용을 **통째로 복사해 붙여넣고** 오른쪽 아래 **Run**
   - "Success. No rows returned"가 나오면 성공
5. 왼쪽 메뉴 **Authentication → Sign In / Providers**(또는 Settings) → **Allow new users to sign up** 끄기
   - 아무나 가입하지 못하게 막는 설정입니다. 담당자는 관리자가 초대합니다.
6. 왼쪽 메뉴 **Project Settings → API Keys**에서 아래 3가지를 확인 (메모장에 잠시 적어두기)
   - **Project URL**: `https://xxxx.supabase.co` (Project Settings → Data API 또는 General에 있음)
   - **Publishable key** (`sb_publishable_...`): 웹사이트용, 공개돼도 괜찮은 키
   - **Secret key** (`sb_secret_...`): 작업기용, **절대 공개 금지**

## 2. 관리자 계정 만들기

1. **Authentication → Users → Add user → Create new user**
   - 이메일, 비밀번호 입력, **Auto Confirm User** 체크 → Create
2. **SQL Editor**에서 아래 한 줄 실행 (이메일만 바꾸기)
   ```sql
   update public.profiles set role = 'admin' where email = '본인이메일@example.com';
   ```

## 3. 웹사이트 올리기 (Cloudflare Pages)

> 코드가 GitHub 저장소에 올라가 있어야 합니다 (개발자가 준비).

1. https://dash.cloudflare.com 가입 (무료)
2. **Workers & Pages → Create → Pages → Connect to Git** → GitHub 연결 → `drc-cs-hub` 저장소 선택
3. 빌드 설정
   | 항목 | 값 |
   |---|---|
   | Framework preset | None |
   | Build command | `pnpm install && pnpm --filter @drc/web build` |
   | Build output directory | `apps/web/dist` |
4. **Environment variables** 추가
   | 이름 | 값 |
   |---|---|
   | `VITE_SUPABASE_URL` | 1-6의 Project URL |
   | `VITE_SUPABASE_PUBLISHABLE_KEY` | 1-6의 Publishable key |
   | `NODE_VERSION` | `22` |
5. **Save and Deploy** → 완료되면 `https://drc-cs-hub.pages.dev` 같은 주소가 생깁니다
6. Supabase로 돌아가 **Authentication → URL Configuration → Site URL**에 위 주소 입력 → Save
   - 초대 메일의 링크가 이 주소로 연결됩니다
7. 위 주소로 접속해 2단계 계정으로 로그인 → 상단에 빨간 "작업기 멈춤"이 보이면 정상 (작업기는 5단계에서 켭니다)

## 4. 담당자 초대

1. Supabase **Authentication → Users → Add user → Send invitation** → 담당자 이메일 입력
2. 담당자가 메일의 링크를 눌러 비밀번호를 정하면 끝
3. 처음엔 '담당자' 권한입니다. 웹사이트 **담당자** 메뉴(관리자만 보임)에서 승인자·관리자로 바꿀 수 있습니다

## 5. 사무실 PC에 작업기 설치

### 5-1. 프로그램 설치 (한 번만)
1. **Node.js 22 LTS**: https://nodejs.org → LTS 버전 Windows Installer(.msi) → 기본값으로 설치
2. **Git**: https://git-scm.com/download/win → 기본값으로 설치
3. **시작 메뉴 → "PowerShell"** 실행 후 한 줄씩 복사해 실행:
```powershell
corepack enable
```
```powershell
cd C:\
```
```powershell
git clone https://github.com/<저장소주소>/drc-cs-hub.git
```
```powershell
cd C:\drc-cs-hub
```
```powershell
pnpm install
```

### 5-2. 이 PC의 IP가 마켓에 등록되어 있는지 확인
```powershell
curl.exe ifconfig.me
```
- 나온 숫자(예: `121.xxx.xxx.xxx`)가 아래 두 곳에 등록되어 있어야 합니다
  - 네이버 **커머스API센터 → 애플리케이션 → API 호출 IP**
  - 쿠팡 **Wing → 판매자정보 → 추가판매정보 → OPEN API 키 → 연동 IP**
  - ⚠ 쿠팡은 IP 수정 횟수가 제한(10회)되어 있으니 정확히 한 번에 입력하세요

### 5-3. 설정 파일(.env) 만들기
```powershell
cd C:\drc-cs-hub\apps\worker
```
```powershell
copy .env.example .env
```
```powershell
notepad .env
```
메모장이 열리면 각 줄의 `=` 뒤에 값을 채우고 저장합니다.
- `SUPABASE_URL`, `SUPABASE_SECRET_KEY`: 1-6에서 확인한 값
- `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`: 커머스API센터 애플리케이션 ID / 시크릿
- `COUPANG_VENDOR_ID`, `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY`, `COUPANG_KEY_ISSUED_AT`: Wing OPEN API 화면의 업체코드 / Access Key / Secret Key / 발급일
- `DATA_GO_KR_SERVICE_KEY`: (선택) 공공데이터포털 「한국천문연구원_특일 정보」 활용신청 후 **일반 인증키(Decoding)**. 비워두면 내장 공휴일 목록을 씁니다
- `DRY_RUN=true`는 **그대로 두세요**

### 5-4. 연결 점검 (DB에 아무것도 쓰지 않음)
```powershell
pnpm worker:probe
```
- 채널마다 ✅ 접속 성공 / ❌ 실패가 나옵니다
- 결과가 `C:\drc-cs-hub\apps\worker\worker-data\probe-결과.txt`에 저장됩니다
- **이 파일을 개발자(Claude)에게 보내주세요.** 키·고객 내용은 들어있지 않고 건수와 필드 이름만 있습니다. 네이버 쪽은 이 결과를 보고 최종 조정합니다

### 5-5. 시험 실행
```powershell
pnpm worker
```
- "작업기 시작" 메시지 후, 운영 시간이면 수집을 시작합니다. 웹사이트 상단이 초록색 "작업기 정상 작동 중"으로 바뀌면 성공
- 멈추려면 `Ctrl + C`

## 6. 작업기 자동 실행 등록 (PC를 켜면 자동으로 시작)

1. https://nssm.cc/download 에서 nssm 압축 파일 받기 → 풀어서 `win64\nssm.exe`를 `C:\nssm\nssm.exe`로 복사
2. **시작 메뉴 → PowerShell 오른쪽 클릭 → 관리자 권한으로 실행** 후 한 줄씩:
```powershell
C:\nssm\nssm.exe install DRC-CS-Worker "C:\Program Files\nodejs\node.exe" "--env-file=.env --import tsx src/index.ts"
```
```powershell
C:\nssm\nssm.exe set DRC-CS-Worker AppDirectory C:\drc-cs-hub\apps\worker
```
```powershell
C:\nssm\nssm.exe set DRC-CS-Worker AppStdout C:\drc-cs-hub\apps\worker\worker-data\service.log
```
```powershell
C:\nssm\nssm.exe set DRC-CS-Worker AppStderr C:\drc-cs-hub\apps\worker\worker-data\service.log
```
```powershell
C:\nssm\nssm.exe set DRC-CS-Worker Start SERVICE_AUTO_START
```
```powershell
C:\nssm\nssm.exe start DRC-CS-Worker
```
3. **PC 절전 끄기**: 설정 → 시스템 → 전원 → 화면 및 절전 → "절전 모드" **안 함**
4. 확인: PC를 재부팅한 뒤 로그인하지 않은 상태에서도 웹사이트 상단이 초록색이면 성공

### 자주 쓰는 명령 (관리자 PowerShell)
| 하고 싶은 일 | 명령 |
|---|---|
| 작업기 재시작 | `C:\nssm\nssm.exe restart DRC-CS-Worker` |
| 작업기 멈춤 | `C:\nssm\nssm.exe stop DRC-CS-Worker` |
| 상태 보기 | `C:\nssm\nssm.exe status DRC-CS-Worker` |
| 기록 보기 | `notepad C:\drc-cs-hub\apps\worker\worker-data\service.log` |
| 새 버전 받기 | `cd C:\drc-cs-hub; git pull; pnpm install` 후 재시작 |

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 웹 상단이 빨간색 "작업기 멈춤" | 사무실 PC 켜짐? `nssm status` 결과가 SERVICE_RUNNING? 인터넷 연결? |
| 점검 결과 쿠팡 ❌ 403 | PC IP가 Wing 연동 IP에 등록되었는지 (5-2), 등록 후 최대 30분 걸림 |
| 점검 결과 네이버 ❌ 401/403 | 애플리케이션 ID/시크릿 오타, API 호출 IP 등록 |
| 점검 결과 네이버 ❌ 400 | 정상일 수 있음 — 결과 파일을 개발자에게 보내주세요 (파라미터 조정) |
| 로그인이 안 됨 | Supabase Authentication → Users에 계정이 있는지, 웹 환경변수가 맞는지 |
| 쿠팡 키 만료 경고 | Wing에서 키 재발급 → `.env`의 COUPANG 값 3개와 발급일 수정 → 작업기 재시작 |
